# Davie Clean: Meta ads

Three 1080×1350 (4:5) feed ads. Edit the `ad-*.html` files, then re-render the PNGs with:

```
node ads/davie-clean/render.js
```

Recommended setup: one campaign (Leads or Messages objective), one ad set targeting about 10–15 miles around Davie, FL, homeowners 28–60, with all three ads in it. Let Meta run them for 5–7 days, then shift budget to the winner.
